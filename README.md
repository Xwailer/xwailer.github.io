# 🛡️ VaultShield - Institutional Crypto & Digital Asset Insurance Protocol

A production-grade, high-performance Web3 & Fintech React.js application built with **Vite**, **React 18**, **react-helmet-async**, and **Lucide Icons**.

Optimized for **instant Crypto & Bitcoin Premium tier monetization** on **A-ADS**, **Ezoic**, **NitroPay**, and **Google AdSense**, with automated deployment to **GitHub Pages** and **Vercel**.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
node ./node_modules/vite/bin/vite.js

# 3. Build for production
node ./node_modules/vite/bin/vite.js build
```

## 🌍 Free 1-Click Hosting on GitHub Pages

1. Create a new repository on **[GitHub.com](https://github.com/new)** (e.g. `vaultshield`).
2. Run in your terminal:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/vaultshield.git
   git branch -M main
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings > Pages**.
   - Under **Build and deployment > Source**, select **GitHub Actions**.
   - Your site will automatically build and publish live at `https://YOUR_USERNAME.github.io/vaultshield/` with free SSL (HTTPS)!

---

## ☁️ Free 1-Click Hosting on Vercel

1. Go to **[Vercel.com](https://vercel.com)**.
2. Click **Add New > Project** and import your GitHub repository.
3. Click **Deploy**. Vercel will automatically build and provide a custom `.vercel.app` domain and free global edge CDN.
